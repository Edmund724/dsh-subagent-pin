# 包名去掉 scope

**决定（2026-09-28）**：发布名从 `@edmund724/dsh-subagent-pin` 改为不带 scope 的
`dsh-subagent-pin`。

## 为什么

- 名字在公共 registry 上未被占用（当日 `npm view dsh-subagent-pin` 返回 404）；
  `subagent-pin` 同样可用，`dsh-pin` 已被占（0.2.1）。
- 安装名更短、书写处更少；本包只有一个发布入口，用不到 scope 提供的命名空间分组。
- `publishConfig.access` 只对 scoped 包有意义，unscoped 下是惰性字段，随之删除
  （`test/package.test.mjs` 只在名字以 `@` 开头时才要求它）。

## 代价与随之必须一起改的

- **失去命名空间归属**：unscoped 全局唯一、先到先得，别人可以注册近似名；改回名字
  几乎只能发新名并把旧名 deprecate。
- **行地址跟着变**：两行从 `@edmund724/dsh-subagent-pin/subagent-pin` 与
  `…/opencode-header` 变成 `dsh-subagent-pin/subagent-pin` 与
  `dsh-subagent-pin/opencode-header`（`cordis.patch.yml`）。装进 profile 的
  `dependencies` 键必须同时改，否则 profile 里解析不到这两行 —— 这是仓库外的
  一步，revert 时要一并还原。
- 条数不变、语义不变：`README.md` / `README-en.md` 的安装与回滚示例、各模块
  `@module`、`opencode-header.js` 的 `Symbol.for` 键、`test/docs.test.mjs` 里那条
  坏基线用的行地址。

## 排除的选项

- **保留 scoped 名**：安装名更长，且 scoped 必须声明 `access: public` 才不至于发成
  restricted（守卫见 `test/package.test.mjs`）。
- **换成 `subagent-pin`**：可用，但丢掉 `dsh-` 前缀，在 registry 搜索里分不出是谁的
  插件。
- **换成别的名字**：只解决"名字被占"这一个问题，本包没遇到它。

## 核实位置

- registry 可用性：`npm view <name> version`（发布那一刻才算数，先到先得）；
- 名字与行地址的一致性：`test/patch.test.mjs`（行名由 `package.json` 的 `name` 推出，
  改名只需改这一个真源）；
- unscoped 不再需要 access 声明：`test/package.test.mjs` 的 publishable 用例。
